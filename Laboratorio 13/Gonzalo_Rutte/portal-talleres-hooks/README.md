# Semana 13 — Hooks de React

Proyecto independiente de la guía de laboratorio 13.

## Requisitos
- Node.js 24 LTS
- Visual Studio Code

## Ejecutar
1. Abre esta carpeta en VS Code.
2. Abre la terminal integrada en la raíz del proyecto.
3. Ejecuta:

```bash
npm install
npm run dev
```

4. Abre la URL local que indique Vite.

## Pruebas opcionales

```bash
npm run verify
```

La configuración de pruebas está en `vite.config.ts` y los tests en `src/lab.test.tsx`.

No mezcles este proyecto con el de la semana 14. Los cupos y reservas de esta guía son simulados y locales.
