# Portal académico – Laboratorio 10 (Angular)

Requisitos: Node.js 24.19.0+ y npm 11.

## Primera vez
```bash
npm install
npm run api:reset
```

## Ejecutar (dos terminales)
```bash
# Terminal A – API simulada
npm run api          # http://127.0.0.1:3000/estudiantes

# Terminal B – aplicación
npm start            # http://localhost:4200
```

## Verificar (compilación de producción + 30 pruebas)
```bash
npm run verify
```
